# Portfolio de Javier Saez

## Ejecutar en local

**Requisito:** Node.js 22.12 o posterior.

1. Instala las dependencias:

   ```sh
   npm install
   ```

2. Inicia el servidor de desarrollo:

   ```sh
   npm run dev
   ```

3. Abre <http://127.0.0.1:3000>.

No hace falta configurar una clave de Gemini para ejecutar el portfolio.

## Comprobaciones

```sh
npm run lint
npm run build
```
